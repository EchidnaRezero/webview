# Project Direction — MotionGraphic (Tool & Harness)

## 1. 이 리포지토리의 정체성

`MotionGraphic`은 단독 포트폴리오 웹사이트가 아니다. **다른 STEM 프로젝트(`XAI_DiT`, `tmp_protein`, 새 논문 리포 등)에서 작업 중인 AI 에이전트(또는 사람)가 로컬에서 불러다 쓰는 쇼케이스 제작 도구·키트·하네스**다.

---

## 2. 해결하려는 문제

1. **반복 보일러플레이트 제거**: 새 프로젝트마다 타임라인 컨트롤러, 다크 사이언티픽 테마, Pretendard 폰트, Report/PT 전환, 3D 카메라 프리셋을 매번 처음부터 다시 짜는 비효율을 없앤다.
2. **시각 품질 자동 보장**: 기존 쇼케이스에서 반복된 헤더 줄바꿈 넘침, Canvas 텍스트-배지 충돌, 좁은 폭 표 넘침, 3D 라벨 겹침, 흰 배경 외부 차트 PNG 혼재 문제를 CLI 자동 검수(`mg check`)로 차단한다.
3. **하이브리드 표현 자유도**: 자유 조작 3D/인터랙션(React + R3F + Motion)과 3B1B 스타일 프레임 동기화 모션/MP4 출력(Remotion)을 AI가 목적에 따라 선택·조합할 수 있게 한다.

---

## 3. 범위 (Keep It Lean)

### In-Scope
- **`kit/`**: 최소한의 핵심 STEM 공용 부품 & 스타터 템플릿
- **`cli/`**: 로컬에서 바로 실행하는 4개 커맨드 (`init`, `check`, `build`, `render`)
- **`skill/`**: 다른 프로젝트의 AI가 읽고 그대로 작업할 수 있는 `SKILL.md`
- **`examples/`**: 키트 검증 겸 AI가 패턴을 참고할 수 있는 1~2개의 깔끔한 STEM 예제 (예: Attention 내부 동작)
- **`docs/`**: 이 도구 자체의 유지보수와 업그레이드를 위한 최소한의 설계·가이드 문서

### Out-of-Scope
- 별도 MCP 서버 구축 (로컬 CLI + `SKILL.md`로 충분; 추후 필요 시에만 검토)
- 노코드 GUI 편집기 / 백엔드 웹 서비스
- 모든 개별 프로젝트의 실제 포트폴리오를 이 리포 안에 몰아넣는 것 (각 프로젝트의 `showcase/`로 출력)
